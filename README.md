# 🏦 Loan Risk Evaluation Project

This project is focused on evaluating and visualizing **loan risk levels** using real-world-style data. 
It was inspired by the need to understand what factors—such as gender, education, income, and property area—play a role in how risky a loan applicant might be.

The goal of this project is to:
- Clean and explore the data using Python
- Identify patterns related to loan risk
- Visualize these insights with clear, meaningful charts

---

## 📁 Dataset Description

- **File Name:** `loan_risk_dataset.csv`
- The dataset includes:
  - `Gender`
  - `Education`
  - `Applicant Income`
  - `Loan Amount`
  - `Property Area`
  - `Loan Risk Level` (our target variable)

The dataset was processed using **Jupyter Notebook**, where I performed data cleaning (handling nulls, formatting issues), exploratory data analysis (EDA), and created visualizations.

## 📈 Key Takeaways

- Most applicants fall into the **medium risk** category.
- Gender and education show some trends, but they aren’t strong predictors alone.
- Income and loan amount combined give a better picture of risk, especially when segmented by area.

This project helped me better understand **risk profiling in finance** and how data can be used to support smarter loan decisions.
It’s also a great example of turning raw data into insights with practical value.
